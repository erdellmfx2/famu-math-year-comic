# Week 13: Beyond the Campus Map

Episodes 85-91 use dialogue-first four-panel boards. Every panel reserves an empty upper wall, sky, or floor-safe zone for later lettering. Generated art must contain no dialogue balloons, captions, readable text, numbers, equations, logos, signs, or readable phone/computer interfaces.

Before acceptance, review each unlettered page for: character identity, face and hand clearance, no generated balloons, no readable content, and a clear speaker tail target.
