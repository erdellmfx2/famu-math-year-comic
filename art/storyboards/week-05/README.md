# Week 05 Storyboards: Kickoff

Sources: `story/timeline-weeks/5.md` and `story/timeline-weeks-prose-v2/prose_5.md`

This week ties limits and continuity to the things the characters cannot yet
name: wanting an afternoon, waiting for a chance, beginning a relationship,
and admitting that the news changes something. Every episode uses two comic
pages. Each page has a dialogue-first balloon map that is binding for
composition, lettering, and per-image review.

## Release Locks

- Use only fictional McCall-Hart visual identity.
- Create unlettered art first. Do not draw text, placeholder balloons, signs,
  equations, logos, or watermarks.
- Keep every mapped lettering zone inside its own panel. Put faces, hands,
  mathematical visuals, decisive props, and emotional action outside it.
- Run the balloon check after every unlettered and lettered image revision.
- Use the approved series title card, local `PART 1` through `PART 7`, the
  approved FAMU Mathematics Department page mark, and one approved closing card.
