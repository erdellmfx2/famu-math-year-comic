# Week 01 Storyboard Pack

## Scope

This pack adapts all seven daily episodes of Week 01, **Two Kinds of Plans**, into one phone-readable four-panel comic page per day. The weekly arc begins with Malik's red budget balance, develops the complementary tension between calculation and context, establishes the fictional McCall-Hart campus, and ends with Malik and Nia becoming accountability partners.

## Source Order

Use both sources for every episode:

1. `story/timeline-weeks/1.md` controls the required daily event and continuity handoff.
2. `story/timeline-weeks-prose-v2/prose_1.md` controls dialogue, interior context, and scene texture.

Read `story/approval_status.json`, `story/setting_bible_v2.md`, `story/character_bible_v2.md`, `art/style_guide.md`, and `art/final/foundational-assets/coordinate-registry.md` before generation.

## Production Rule

Generate an unlettered art pass first, inspect it, then add only storyboard-listed captions and dialogue in a second lettering pass. Save final pages under `art/final/week-01/episode-XX/` and never use archived visual material.
