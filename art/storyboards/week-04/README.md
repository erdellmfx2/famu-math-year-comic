# Week 04 Storyboards: The First Limit

Sources: `story/timeline-weeks/4.md` and `story/timeline-weeks-prose-v2/prose_4.md`

This week introduces Calculus I as a study of behavior near a point, while
Malik learns that alternate status and Nia's new relationship can be true
without defining everything around them. Every episode uses two comic pages.
Each page has a dialogue-first balloon map that is binding for composition,
lettering, and per-image review.

## Release Locks

- Use only fictional McCall-Hart visual identity.
- Create unlettered art first. Do not draw text, placeholder balloons, signs,
  equations, logos, or watermarks.
- Keep every mapped lettering zone inside its own panel. Put faces, hands,
  mathematical visuals, decisive props, and emotional action outside it.
- Run the balloon check after every unlettered and lettered image revision.
- Use the approved series title card, a local `PART 1` through `PART 7`, the
  approved FAMU Mathematics Department page mark, and one approved closing card.
