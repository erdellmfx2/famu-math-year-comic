# V2 Final Art

This active directory holds approved v2 continuity assets and completed comic pages.

The v2 script and comic production are approved in `story/approval_status.json`.
Use `foundational-assets/coordinate-registry.md` to cite the character, setting,
and prop reference coordinates used by each page.

Save only McCall-Hart continuity assets and completed pages here. Never copy
archived legacy art into this path.
