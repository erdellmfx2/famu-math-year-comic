# McCall-Hart Foundational Asset Boards

These are the active v2 continuity references for *The Formula of Becoming*.
Every reusable item is addressed with a board identifier and a grid coordinate,
for example `CHAR-MALIK:B2` or `ENV-ATHLETICS:C1`. Use an asset coordinate in
storyboards and image prompts whenever a recurring character, setting, prop, or
composition appears.

## Board Types

- `CHAR-*`: 4 columns by 4 rows. Columns run left to right (`A` through `D`);
  rows run top to bottom (`1` through `4`).
- `ENV-*`: 3 columns by 3 rows. Columns run left to right (`A` through `C`);
  rows run top to bottom (`1` through `3`).
- `PROP-*`: 4 columns by 4 rows. Columns run left to right (`A` through `D`);
  rows run top to bottom (`1` through `4`).
- `COMP-RELATIONSHIPS`: 3 columns by 3 rows. Columns run left to right (`A`
  through `C`); rows run top to bottom (`1` through `3`).

## Reuse Rule

The coordinate tells a storyboard artist what to preserve, not the only angle
that may ever be used. Keep the person, palette, silhouette, hair, wardrobe,
prop design, or location architecture visually consistent with the coordinate.
Specify a new camera angle, pose, or lighting only after naming the source
coordinate.

## Files

- `coordinate-registry.md`: the canonical item-to-coordinate map.
- `characters/`: individual character reference boards.
- `environments/`: recurring campus, community, and career settings.
- `props/`: personal and story-critical reusable items.
- `compositions/`: repeatable multi-character staging references.
