# Current Comic Materials

This folder is the quick-access shelf for the latest approved or review-ready comic materials.

## Weeks

- `week-01/` - current expanded Week 1 social-media pages, storyboards, and PDF.
- `week-02/` - current Week 2 face-clear lettered social-media pages, storyboards, and PDF.

## Folder Pattern

Each week uses the same structure:

- `social-pages/day-XX/` - the title card, comic pages, and end card for that day.
- `storyboards/` - storyboard markdown files for the week.
- `pdf/` - the complete social-media-size PDF for the week.

These files are links to the production archive, not duplicate exports. The source materials remain in `art/final/`, `art/storyboards/`, and `output/`.
