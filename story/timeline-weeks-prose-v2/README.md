# Prose v2 Production Tracker

## Purpose

This folder contains the active prose adaptation of *The Formula of Becoming*. The prose is written for flexible reuse in serialized reading, social media excerpts, audio narration, and later long-form publication.

The active weekly scripts in `story/timeline-weeks/` are the continuity source. Archived v1 prose is a format reference only and must not supply obsolete setting details, plot events, or real-university identity.

## Format Standard

- Adapt one story week per Markdown file named `prose_<week>.md`.
- Work in consecutive three-week batches.
- Expand all seven daily beats into connected scenes rather than restating the outline.
- Use vivid third-person narration, natural dialogue, humor, and emotionally honest stakes appropriate for teen and young-adult audiences.
- Make mathematics part of choices and consequences without turning scenes into lessons.
- End each week with forward momentum into the next chapter.
- Preserve the fictional McCall-Hart University setting and all v2 character and relationship guardrails.
