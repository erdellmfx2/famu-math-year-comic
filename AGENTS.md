# Working in *The Formula of Becoming*

Before doing any active story, art, video, production, release, campaign, or outreach work, read:

1. `COMPASS.md`
2. `story/approval_status.json`
3. The task-relevant authority named in the compass (for example, the setting/character/season bible, approved script, or production-and-posting loop)

## Operating Rule

Treat `COMPASS.md` as the strategic authority for the project. Treat the active v2 story authorities as canon. Do not use archived FAMU material as active canon or publish it as McCall-Hart material.

Pause and clearly flag any request or proposed change that conflicts with the compass, including a conflict involving fictional-setting identity, legacy institutional marks, mathematical integrity, character agency, G-rated audience care, accessibility, approval status, or sustainable production/release practice.

Do not revise `COMPASS.md` without explicit user approval.
